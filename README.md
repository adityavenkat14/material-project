 Material Intelligence: ROI Calculator

A web app that estimates the financial return of adopting material-tracking software.

**Live demo:** https://material-project-beta.vercel.app/

## Features
- Industry presets (Pharmaceuticals, Automotive)
- Inputs: annual production, failure rate, inventory value, software cost
- Outputs: annual benefit, ROI, payback period
- Charts: savings distribution and ROI sensitivity
- Word report export

## Tech stack
Next.js, React, Vercel
